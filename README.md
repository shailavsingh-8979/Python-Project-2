# 📝 Python Text Editor App

A simple desktop Text Editor application built using **Python**.  
This app allows users to create, open, edit, and save text files with an easy-to-use interface.

---

## 🚀 Features
- Create a new text file
- Open existing `.txt` files
- Edit text easily
- Save files to local system
- Simple and user-friendly GUI

---

## 🛠️ Technologies Used
- Python
- Tkinter (GUI Library)
